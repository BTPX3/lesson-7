
# CSS Box Model — Навчальні картки

## Мета проєкту

Продемонструвати роботу CSS Box Model,
властивостей розмірів, внутрішніх і зовнішніх
відступів, рамок та позиціювання елементів.

## Використані технології

- HTML5
- CSS3

## Використані властивості

- `box-sizing: border-box` — включає padding
  і border до загальної ширини елемента.
- `padding` — створює внутрішні відступи.
- `border` — задає рамку елемента.
- `margin` — створює зовнішні відступи.
- `position: relative` — задає контекст позиціювання.
- `position: absolute` — позиціонує позначку
  відносно першої картки.
- `overflow: auto` — запобігає
  виходу довгого тексту за межі картки.
- `max-width` — обмежує ширину карток.

## Структура

Проєкт містить рівно дві навчальні картки.

Перша картка має синю рамку та позначку «Нове».
Друга картка має зелену пунктирну рамку.

## Перевірка в DevTools

Перевірив властивості Box Model: content, padding, border і margin. Також перевірив позиціювання позначки «Нове», її прив'язку до першої картки та читабельність заголовка.

Змінив ширину вікна браузера, щоб перевірити адаптивність карток. На перший погляд, усе працює правильно: картки відображаються коректно, позначка не перекриває текст, горизонтальний скрол не з'являється.
